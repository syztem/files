01 — the instrument

Five skies,
one aperture.

Each plate is fetched, parsed and swapped into the frame by htmx 4 — no reload, no photographer. The aperture is a single svg element, and the new sky arrives the way a server would send it.

Observations, logged.

Three plates from the archive. Each one is unbound from the server only when it crosses the edge of the viewport, and each one arrives as markup, not as data.
